# TravelIt Alpha

Temporary **public GitHub Pages** staging repository for TravelIt v0.29 iPhone acceptance testing.

**Testing only.** Do not enter real family records, IDs, bookings, or sensitive documents. TravelIt currently stores trip data locally in the browser and does not provide cloud synchronization.

The app should be published from the `main` branch root after the reviewed deployable application files are uploaded. The final app does not depend on GitHub Pages.
